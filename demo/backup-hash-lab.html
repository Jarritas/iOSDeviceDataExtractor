Backup Hash Lab

Un respaldo de iPhone no guarda los archivos con su nombre real. Cada archivo se renombra con el SHA-1 de Dominio-ruta/relativa y se coloca en una carpeta con los dos primeros caracteres del hash. Escribe una ruta y mira dónde quedaría dentro del respaldo.

Estructura del respaldo

├─ Info.plist      # modelo, iOS, IMEI
├─ Manifest.plist  # ¿cifrado? claves
├─ Manifest.db     # índice de archivos
├─ Status.plist    # estado del respaldo
├─ 3d/
│  └─ 3d0d7e5f…3a28  # sms.db
└─ 31/
   └─ 31bb7ba8…e442  # contactos

Qué hace el módulo

El plugin de Autopsy crea el respaldo del dispositivo, lee Manifest.db para mapear cada hash a su ruta original y reconstruye el árbol de carpetas. Si el respaldo está cifrado, primero descifra la base con la contraseña. Al final puede comprimir todo en un ZIP listo para iLEAPP.

Esta página reproduce solo el paso del hash, que es el que permite encontrar un archivo concreto sin abrir la base.
